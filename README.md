Ang akong Java program naggamit ug tulo ka sorting algorithms: Bubble Sort, Selection Sort, ug Insertion Sort. Ang program naay original array nga naay 10 ka dili sunod-sunod nga numero. Gihimo nako nga separate copy ang original array para magamit sa kada sorting method. Human, i-sort sa kada algorithm ang mga numero gikan sa pinakagamay taman sa pinakadako. I-display sa program ang original array ug ang resulta sa kada sorting algorithm.

Ang Bubble Sort nagkumpara sa duha ka nagtapad nga numero. Kung mas dako ang numero sa una kaysa sa numero sa ikaduha, ilang ibaylo ang ilang posisyon. Balik balik nga proseso hangtod ang tanan numero mahan-ay na gikan sa gamay padulong sa dako.Ang pinakadako nga numero anam-anam nga mapadulong sa tapos na bahin sa array.

Ang Selection Sort mangita una sa pinakagamay nga numero sa array. Human makit-an, ibutang sa unang posisyon. Sunod, mangita na usab kini sa pinakagamay nga numero sa nahibiling wala pa natarong nga mga numero. Balikon kini hangtod mahuman ang paghan-ay sa tanan nga numero.

Ang Insertion Sort magsugod sa ikaduhang numero ug ikumpara kini sa mga numero nga naa sa wala. Kung mas gamay ang numero, ibalhin ang mas dagkong numero para makahimo og lugar. Dayon isulod ang numero sa tsakto na posisyon. Padayonon hangtod maplastar ang tibuok array.


1. How does each sorting algorithm arrange numbers? What makes their processes different?

Ang kada sorting algorithm naay kaugalingong pamaagi sa paghan-ay sa mga numero. Ang Bubble Sort nagkumpara sa magtapad nga numero ug magbaylo kung dili mao ang ilang pagkasunod-sunod. Ang Selection Sort mangita sa pinakagamay nga numero ug ibutang sa unahan. Ang Insertion Sort nagkuha ug usa ka numero ug mangita sa hustong lugar.

2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?

Para saako, ang Bubble Sort ang pinakasayon sabton ug buhaton. Kini tungod kay simple ra ang proseso. Kinahanglan ra nako ikumpara ang duha ka nagtapad nga numero ug ilisan ang ilang posisyon kung kinahanglan. Dali ra nako masabtan kung giunsa paghan-ay ang mga numero tungod kay makita nako ang paglihok sa matag numero.

3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.

Para nako, ang Insertion Sort ang mas maayo kung ang mga numero naplastar nadaan. Kini tungod kay dili na kinahanglan ibalhin ang mga numero kung sakto na ang ilang posisyon. Ikompara ra ang matag numero ug magpadayon sa sunod nga numero. Mas gamay ang trabaho nga buhaton niini kung sorted na daan ang array.

4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?

Kung modaghan ang mga numero sa array, mas modaghan ang trabaho sa tulo ka sorting algorithms. Ang Bubble Sort maghimo ug daghang comparisons ug swaps. Ang Selection Sort magpadayon sa pagpangita sa pinakagamay nga numero sa nahibiling wala pa mahan-ay. Ang Insertion Sort kinahanglan usab magbalhin og daghang numero aron maibutang ang kada sa hustong lugar.Mas madugay ang ilang pag-sort kung modaghan ang datos, labi na kung daghan kaayo ang mga numero.

5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?

Isip usa ka future programmer, importante nga masabtan nako ang lain-laing sorting algorithms kay dili tanan parehas og performance sa kada sitwasyon. Adunay algorithm nga mas angay gamiton kung gamay ra ang numero, ug mas maayo kung daan nang han-ay ang mga numero. Kung masabtan nako ang ilang mga kalainan, mas makahimo ko og maayong desisyon kung unsang algorithm ang gamiton. Makatabang kini aron mahimong mas maayo ang akong mga program.
